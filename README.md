# -Samba-Linux-Active-Directory
Скрипт установки Samba на Linux, с авторизацией в Active Directory

Сделайте файл исполняемым:
chmod +x install_samba.sh

Запустите скрипт установки:
./install_samba.sh

Дальше работайте согласно пунктам меню:

============================================
  Samba Domain Member Management Script
============================================

ГЛАВНОЕ МЕНЮ:
1. Полная установка Samba (доменный член)
2. Управление доменным подключением
3. Добавить общую папку
4. Удалить общую папку (по номеру)
5. Проверить состояние системы
6. Выход
